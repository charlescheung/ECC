# PRD：用户修改个人资料

## 1. 业务目标

允许已登录用户自助修改个人资料，降低客服介入成本，提升用户留存率。

## 2. 用户故事

- 作为已登录用户，我希望能修改昵称，以便在社区中展示我偏好的名字。
- 作为已登录用户，我希望能上传头像，以便让其他用户认出我。
- 作为已登录用户，我希望能编辑个人简介，以便向他人介绍自己。

## 3. 功能范围

| 字段 | 类型 | 限制 |
|------|------|------|
| 昵称 | 文本 | 1–20 字符，不可全空格 |
| 头像 | 图片 | JPG/PNG，≤ 2MB，上传至 OSS |
| 个人简介 | 文本 | 0–200 字符 |

## 4. 接口设计

### PUT /api/users/profile

**请求体：**
```json
{
  "nickname": "string",
  "avatarUrl": "string",
  "bio": "string"
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "id": "string",
    "nickname": "string",
    "avatarUrl": "string",
    "bio": "string",
    "updatedAt": "ISO8601"
  }
}
```

**错误码：**
| 码 | 含义 |
|----|------|
| 400 | 字段校验失败 |
| 401 | 未登录 |
| 413 | 头像文件过大 |

## 5. 前端行为

- 表单提交时禁用按钮，避免重复提交。
- 修改成功后，全局用户状态同步更新，无需刷新页面。
- 错误时在字段下方展示具体提示文案。

## 6. 非功能要求

- 接口响应时间 P95 ≤ 300ms。
- 头像上传成功率 ≥ 99.9%。

## 7. 验收标准

1. 昵称为空或超过 20 字符时，提交被拦截并提示错误。
2. 上传超过 2MB 的图片时，返回 413 错误。
3. 修改成功后，页面头部昵称和头像即时更新。
4. 未登录用户访问该接口返回 401。
